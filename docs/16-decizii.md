# 16. Decizii si motivele lor

Fiecare decizie importanta, de ce a fost luata si ce alternativa a fost respinsa. Cand iei o decizie noua, o adaugi aici.

## Forma jocului

| Decizie | De ce | Alternativa respinsa |
|---|---|---|
| Vedere de sus | Cerere: nimic care cere sarituri precise. Cel mic nu a tinut un controller. | Platformer lateral. |
| Un singur ecran, camera care face zoom out | Cei doi copii vad mereu ambii eroii. Nu se pot "pierde". | Ecran impartit in doua: mai greu de urmarit pentru un copil de 6 ani, fiecare jumatate e mica. |
| Zoom minim 0.6 | Sub 0.6 personajele devin prea mici pe un televizor. | |
| Lume de 3200 x 1800 | Destul pentru 60 de oua si obstacole. La zoom 0.6 aproape toata inaltimea incape pe ecran. | |
| Oua in 3 valuri, de la stanga la dreapta | Tinta mereu aproape. Ritm: val, Ciori pe cer, val. Nivelul are un "inainte". | Toate ouale odata: copiii nu stiu unde sa mearga. |
| 40% din oua pe drum | Primul lucru pe care il vad copiii este o dara de oua de urmat. | |
| Fara vieti, fara Game Over | Cerere explicita. Pierderea unui ou este destula consecinta. | |
| Oul scapat cade intr-un loc in care se poate ajunge | Altfel copilul vede un ou pe care nu il poate lua. | |
| Invulnerabilitate 1.6 s dupa ameteala | Fara ea, un gandac te putea lovi de doua ori la rand. | |
| Eroul nejucat merge singur dupa prieten si nu pierde oua | Un copil poate juca singur. Fratele poate pleca la jumatate. | Eroul ramane pe loc si e lovit. |
| Nivelul se termina cand ambii ajung la cuib (sau unul dupa 7 s) | Final de echipa. 7 s ca un copil sa nu astepte la nesfarsit. | |

## Puterile

| Decizie | De ce |
|---|---|
| Tropaitul in toate directiile, cu raza mare | Nu trebuie tintit. Perfect pentru 6 ani. |
| Tropaitul trage ouale | Il face pe cel mic util, nu doar "cel care ameteste". |
| Ouale trase zboara pana la Bubu, oricat de departe | Prima versiune le tragea doar 1.5 s. Unele ramaneau in locuri incomode. |
| Sutul incarcat optional | Cel mare are o indemanare de invatat. Cel mic poate apasa scurt pe Ușor. |
| Mingea se intoarce singura | Nu se pierde. Nu trebuie mers dupa ea. |
| Ajutor la tintire doar pe Ușor | Pe Normal tintirea este provocarea. |
| Steaua din copac iese doar la un sut incarcat | O stea pentru cel mare. Tropaitul arata doar indiciul "tine ✕", ca cel mic sa il cheme pe frate. |
| Steaua de pe insula se ia cu mingea | Alt fel de provocare pentru cel mare. |

## Mini-lupte (al doilea update)

| Decizie | De ce |
|---|---|
| Ritm fix: pregatire (rosu pe jos), atac, oboseala ("Acum!") | Un tipar clar de invatat. Totul se anunta inainte: nimic nu loveste din senin. |
| Doar loviturile pe paznicul obosit conteaza (Normal si Greu) | Cel mare trebuie sa astepte momentul, nu doar sa apese. |
| Pe Ușor orice lovitura conteaza | Cel mic poate ajuta oricand. |
| Paznicul il ataca pe cel mai greu jucator | Cerut: cel mic "sa nu aiba prea multe de facut". |
| Cel mic pe Ușor care doar ajuta nu poate fi lovit | Gasit in teste: conurile aruncate in jur il loveau in timp ce aduna ouale. |
| Adapostul din cuib | Cerut: cel mic "sa stea ascuns in cuib". |
| 4 oua la fiecare lovitura | Cerut: cel mic "sa adune ouale care apar din lupta". |
| Tropaitul face paznicul sa se clatine, iar atunci mingea conteaza | O combinatie de echipa pentru cei doi frati. |
| Sase paznici diferiti, trei tipare | Varietate fara sa trebuiasca invatate sase reguli. |
| Paznicul zburator obosit coboara langa cel care se lupta | In teste, bufnita obosea departe si lupta dura peste 3 minute. |
| Nivelul asteapta pana la 14 s ca ouale din lupta sa fie adunate | Altfel nivelul se termina inainte ca cel mic sa le ia. |
| Muzica separata pentru lupte (Mi minor, 104) | Schimbarea de ritm anunta ca e un moment special. Nu sperie: tot pentatonic, tot marimba. |

## Interfata

| Decizie | De ce |
|---|---|
| Iconite in loc de text unde se poate | Cel mic nu citeste. |
| ✕ desenat ca butonul real | Copilul cauta pe controller ce vede pe ecran. |
| Inel colorat sub fiecare erou | Fiecare copil isi gaseste eroul imediat. |
| Numele deasupra eroului doar 5 s | Dupa aceea ar aglomera ecranul. |
| Copacul devine transparent cand un erou e in spatele lui | Gasit la prima versiune: Leo disparea in padure. |
| Sageata ajutatoare transparenta (maxim 55%), cu bula | Cerut "cu transparenta, sa nu ii ia tot focusul". Bula spune ce e acolo fara cuvinte. |
| Bara de progres ca un drum cu semne | Cel mic nu citeste procente, dar vede punctul care se apropie de cuib. |
| Medalii la final de nivel | Cerut ca jocul sa fie mai provocator pentru cel mare. Medaliile sunt optionale: nu blocheaza nimic. |
| Setari accesibile cu controllerul, tastatura si mouse-ul | Parintele foloseste mouse-ul, copiii controllerul. |
| Controllerele nu se atribuie singure cat sunt deschise Setari | Altfel o apasare in meniu putea lega un controller de eroul gresit. |
| Setarile se salveaza imediat | Nu exista buton "Salveaza" de uitat. |
| Schimbarea personajelor muta si setarile copilului | Controllerul, tastele si dificultatea sunt ale copilului, nu ale personajului. |
| Tastele dupa pozitia fizica (`code`) | Merg pe orice aranjament de tastatura. |
| Tastele P, F, Escape, Backspace rezervate | Altfel un copil putea sa isi puna puterea pe P si sa nu mai poata deschide pauza. |
| Cand o tasta e deja folosita, cele doua se schimba | Nu exista doua actiuni pe aceeasi tasta si nu trebuie dat un mesaj de eroare. |

## Grafica

| Decizie | De ce |
|---|---|
| Totul pictat cu cod, fara imagini | Cerere: un singur fisier, nimic extern. |
| Margini tremurate (`blobPath`) | Cerere: "slightly irregular wobbly edges". |
| Straturi transparente si margine mai inchisa (`wash`) | Asa arata acuarela reala: pigmentul se aduna la margine. |
| Personajele opace | Trebuie sa se vada clar pe fundal. |
| Hartie si vinieta peste tot, cu `multiply` | Cerere. Leaga tot ecranul intr-o singura ilustratie. |
| Fundal pictat o data | Cerere de performanta. O pictura cu zeci de mii de trasaturi nu se poate reface la fiecare cadru. |
| Doua pete per celula pentru noroi si apa | Prima versiune avea patrate vizibile. |
| Cerul spre apus de la nivel la nivel | Cerere. Povestea are un ceas: soarele. |
| Fara negru si gri | Cerere. |

## Sunet

| Decizie | De ce |
|---|---|
| Muzica generata din samanta, pe scara pentatonica | Nu sunt fisiere audio. Pentatonica nu are note care sa sune gresit. |
| Programare dupa ceasul audio, nu dupa cadre | Muzica nu se poticneste cand un cadru e lent. |
| Trei volume (muzica, ambient, personaje) | Cerut in al doilea update. |
| Compresor si trece-jos pe tot | Multe sunete odata nu devin aspre. |
| Voci de desen animat fara cuvinte | Personajele au personalitate in orice limba. Cuvinte reale ar fi trebuit inregistrate. |
| Bubu cu voce joasa, Leo cu voce inalta | Copiii recunosc dupa sunet cine a facut ceva. |
| Pasi cu sunet diferit pentru fiecare erou | Cerut ("sunete cand merge"). |
| Sunetele personajelor in difuzorul controllerului, cand se poate | Cerut. Limitat de ce permite macOS. |
| Vocea citeste povestea cu vocea sistemului | Cerere. Nu se pot include voci in fisier fara inregistrari. |

## Cod

| Decizie | De ce |
|---|---|
| 13 fisiere lipite cu `cat` | Un fisier final cerut, dar cod usor de citit. Fara unelte in plus. |
| `CONFIG` sus | Cerere. |
| Texte in `STR` cu `T()` | Doua limbi cerute. Un singur loc pentru toate textele. |
| Niveluri generate, cu verificarea drumului | Mai putine date de scris de mana. Verificarea garanteaza ca orice ou poate fi luat. |
| Grila de 40 | Destul de fina pentru coliziuni si verificare, destul de mare pentru viteza. |
| `window.__game` | Testele automate pot juca si verifica jocul. |
| Erorile prinse si afisate pe ecran | Un parinte vede ce s-a intamplat si poate spune mai departe. |
